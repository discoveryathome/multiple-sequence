# Independent contributor trial protocol

This package has author-run checks, not an independent newcomer trial. Give a new
contributor only README/DISCOVERY and a seeded task draw. Record setup time, time
to first valid artifact, all attempts, CPU/wall budget and reviewer minutes.

1. Run `python3 scripts/pick.py` and retain its executed seed. Choose a different
   family/method scope from any active local claim.
2. Run the card's first step. The preparation portfolio's incumbent is the starting
   target; the older initial table is a historical control.
3. Use a bounded 30–45 minute session. Search from sequences and frozen incumbents,
   without reading reference metrics to choose moves, seeds or retained outputs.
   Capture source/input hashes, stopping rules and all failed attempts.
4. Save a FASTA candidate under a new research directory. Run `scripts/readiness.py
   check` for its explicit dataset, then freeze its hash before running `evaluate`.
5. Report score and every reference metric, including deterioration. A verified
   negative finding, a correct faster equivalent kernel, or a checker counterexample
   can be a useful contribution. No automatic biological acceptance follows.

The three single-row optima are BB11001, BB11029 and BB20029. Ordinary repeated
single-row sweeps on those starts are retired. Their multi-row escape task is
explicitly separate. BB20036 is a partial-row scaling probe; keep state-budget
failures and distinguish a partial attempt from a completed full-family method.

A first beta should be a few independently reviewed sessions, followed by a decision
based on useful artifacts, scientific validity and review burden. No donor-throughput
claim is inferred from this author's preparation work.
